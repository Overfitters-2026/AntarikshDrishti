Google Earth Studio Animation Directory
========================================

Place your Google Earth Studio WebM / video asset here:
Target path: /assets/earth/antrix-earth.webm

This file is referenced by /src/config/earthConfig.ts via:
videoSrc: "/assets/earth/antrix-earth.webm"

Supported formats:
- .webm (recommended for web performance and alpha transparency)
- .mp4 (H.264 / AV1)

When present, Antariksh Drishti will stream this asset automatically in Earth Studio mode.
If not yet present or if browser autoplay is constrained, the platform gracefully displays
the high-resolution satellite orbital fallback poster with active telemetry crosshairs.
